# Customer Churn Analysis using Python and SQL

## Project Overview

This project analyzes customer churn data to understand customer behavior, identify churn patterns, and evaluate revenue at risk.

The project uses Python, Pandas, NumPy and SQLite for data cleaning, data transformation, database integration and exploratory data analysis.

## Technologies Used

- Python
- Pandas
- NumPy
- SQL
- SQLite
- Jupyter Notebook

## Project Workflow

### 1. Data Importing
- Imported customer data from Excel.
- Converted Excel sheets into SQLite database tables.
- Loaded database tables into Pandas DataFrames.

### 2. Data Cleaning
- Renamed columns.
- Handled missing country values.
- Removed unnecessary columns.
- Converted date columns into datetime format.
- Standardized gender values.

### 3. Data Integration
- Joined customer, subscription and support datasets.
- Created a consolidated dataset.
- Exported cleaned data into CSV format.

### 4. Feature Engineering
- Created customer churn flag.
- Calculated customer age.
- Calculated customer tenure.
- Categorized customer churn risk.

### 5. Exploratory Data Analysis

Analyzed the following business metrics:

- Customer Churn Rate
- Customer Retention Rate
- Churn by Plan Type
- Churn by State
- Churn by Subscription Type
- Average Revenue Per User (ARPU)
- Average Customer Tenure
- Revenue at Risk
- Escalation Rate
- Average Complaints Per User
- Correlation between Escalations and Churn
- Customer Churn Risk Categories

## Project Objective

To understand customer churn behavior, analyze subscription patterns and identify potential revenue risks using data analysis techniques.
